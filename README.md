# Digital Text Methods

This repository contains coding tutorials and sample materials for **ENG 3121/6122: Digital Text Methods** at Seton Hall University. Tutorials will be added throughout **Fall 2026** and are designed to introduce students to computational approaches to literary and textual analysis using Python and Google Colab.

Topics will include corpus construction and metadata, text cleaning, frequency analysis, keyness and collocation, part-of-speech tagging and named entity recognition, topic modeling, and text classification.

No prior coding experience is required. Tutorials are designed to be run in Google Colab and adapted for students' own corpus research projects.

Access additional course materials at https://meganskane.com/courses.html
